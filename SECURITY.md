# Security

## Reporting a security problem

Please email team@digitalhabits.org rather than opening a public issue. Describe the issue, how to reproduce it, and which version of Digital Habits: Focus you use and in which browser. We reply within three days, treat security problems as our top priority, and let you know when a fix is released.

If you use this extension with Digital Habits: Blocker for website blocking and the problem involves Blocker, report it in the same way in the same email.

## Anything else

Either reach out at team@digitalhabits.org or open an issue at <https://github.com/digitalhabits/dh-focus/issues>.
